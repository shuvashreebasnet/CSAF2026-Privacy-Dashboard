# CSAF2026-Privacy-Dashboard
Interactive dashboard that shows what sensitive phone permissions apps have access to, when they occurred, and whether the access is reasonable given app purpose. Recognize unnecessary access, make informed privacy decisions, and understand what apps have access to.

Link: https://csaf2026-privacy-dashboard.vercel.app/
Visitors at the Cybersecurity Awareness Fair 2026 will be able to interact with the demo through laptops and phones.
